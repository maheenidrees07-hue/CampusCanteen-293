# CampusCanteen-293
In this project, I developed a **Campus Canteen website** using React and Vite. The main purpose of this website is to provide students with an easy way to explore canteen food items and view their details. I designed the website with a mustard yellow and olive green color theme, attractive headings, food images, and a clean layout to make it visually appealing and user-friendly.
I also worked on the menu section, where users can browse food items, filter the menu, and add items to the cart. I used JSX to structure the components and CSS to style the website, including the hero section, food cards, and responsive layout.
